# עפרי גיספאן – אתר תדמית

אתר של עמוד אחד (HTML יחיד, ללא תלויות בנייה) עבור עפרי גיספאן, פסיכותרפיסטית גוף, נפש ורוח.
טיפול עומק רגשי-תודעתי, בקליניקה בקדימה-צורן ואונליין בזום.

- כל האתר נמצא בקובץ `index.html` (עיצוב, תמונות וסקריפטים בתוכו).
- הניווט בין העמודים מתבצע בכתובת אחרי הסימן `#` (למשל `#about`, `#approaches`, `#post-mother`).
- הפרסום נעשה דרך GitHub Pages מהענף `main`.
