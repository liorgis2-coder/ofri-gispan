# גרסת וורדפרס

`ofri-theme/` הוא ערכת עיצוב (Theme) לוורדפרס שמשחזרת את האתר מ-`index.html` אחד לאחד, אבל כל עמוד מקבל כתובת אמיתית (`/about/`, `/approaches/`, `/blog/`...) והבלוג הוא פוסטים של וורדפרס – כך שאפשר לפרסם אליו אוטומטית (samurAI Autopilot, דרך WordPress REST API וסיסמת אפליקציה).

## מה קורה בהפעלת ה-Theme

בפעם הראשונה שמפעילים את ה-Theme (`inc/setup.php`):

- נוצרים כל העמודים הקבועים (slug לכל עמוד, ראו `inc/pages.php`).
- `home` הופך לעמוד הבית ו-`blog` לעמוד הפוסטים.
- מבנה הקישורים נקבע ל-`/%postname%/`.
- שלושת המאמרים הקיימים נוספים כפוסטים (`seed/posts.json`), עם הקטגוריות רגש / תודעה.
- הפוסט והעמוד לדוגמה של וורדפרס עוברים לפח, רק אם לא נערכו.

אפשר להפעיל שוב בבטחה – שום דבר לא משוכפל.

## מבנה

| קובץ | תפקיד |
|---|---|
| `templates/page-{slug}.php` | גוף העמוד המעוצב, כפי שהיה ב-`index.html` |
| `index.php` | רשימת הבלוג וארכיוני הקטגוריות |
| `single.php` | מאמר בודד – כל פוסט חדש (גם אוטומטי) מוצג כאן בעיצוב האתר |
| `page.php` | עמודים קבועים; עמוד חדש שנוצר בעורך מוצג במסגרת פשוטה |
| `parts/` | כותרת, תפריט, סיום העמוד, אייקונים, וילון המעבר בין עמודים |
| `assets/` | CSS, JS, צייר התמונות ותמונת הפורטרט |

כותרות ותיאורי SEO לכל עמוד נמצאים ב-`inc/pages.php`. אם מותקן Yoast או Rank Math – הם לוקחים פיקוד.

## הרצה מקומית

```bash
npx -y @wp-playground/cli@latest server --port=9400 --mount=wordpress/ofri-theme:/wordpress/wp-content/themes/ofri-theme --blueprint=wordpress/blueprint.json
```

ואז לפתוח http://127.0.0.1:9400 (משתמש admin מחובר אוטומטית).
